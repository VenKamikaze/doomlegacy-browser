# Bugs and quirks found in upstream Doom Legacy 1.48.18 (r1749)

Found while setting up the repository, in F1 and in 00. Before fixing any of them, check whether a later upstream SVN revision already has: the SVN repository on SourceForge could not be browsed from the cloud container on 19 Nov 2026.

| L1 | **Sprite columns read far out of bounds on 64-bit builds.** Sprites set `dc_texheight = 0` ("no wrap"). `R_DrawColumn_32` computes `unsigned int heightmask = dc_texheight - 1` = `0xFFFFFFFF`, and when `frac` is negative at the top of a sprite (seen: `frac = -6`), `dc_source[(frac>>FRACBITS)&heightmask]` indexes `dc_source[4294967295]`.
